HOW TO USE
----------
1. Upload the ENTIRE folder (HTML + images) to your web server, keeping
   the /images subfolder next to the .html file. The HTML references
   images via a relative path ("images/filename.jpg"), so the folder
   structure must stay intact.

2. If you're placing this on a live domain, put it at a URL like:
      https://www.kodrank.com/services/technical-seo/
   ...to match the canonical URL already set inside the HTML.

IMAGE SEO NOTES
---------------
- Filenames are hyphenated, lowercase, and contain the focus keyword
  ("technical-seo-services") so Google's image crawler can understand
  what each image is about without opening the file.
- These images are used as CSS backgrounds (decorative), so they don't
  carry alt text — that's standard practice for background images. If
  you later choose to convert any of them into inline <img> tags for
  extra visibility in Google Images, add descriptive alt text like:
      alt="Technical SEO services dashboard showing site performance,
           crawl data, and architecture diagram"
